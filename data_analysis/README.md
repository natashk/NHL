# NHL Data Analysis

Statistical analysis of NHL skater data, exploring questions about player performance using hypothesis testing, descriptive statistics, and visualization.

## Notebooks

### forward_defence.ipynb

**Question:** Do forwards score significantly more points per game than defensemen?

**Method:**
- Descriptive statistics comparing points-per-game (PPG) between position groups
- Visualizations: histograms of PPG and games-played distributions by position, boxplot comparison
- One-sided Welch's t-test testing whether forwards' PPG is significantly greater than defensemen's

**Key finding:** Forwards had a significantly higher average PPG than defensemen (p < 0.001), consistent with forwards' primary offensive role.
